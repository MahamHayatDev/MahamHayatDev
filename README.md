## How I Work

- **Tested, not guessed.** My agents ship with evaluation suites, and I publish the failures as well as the wins.
- **Human in the loop.** Important decisions go through an approval step, never straight to the customer.
- **Reliable by design.** I pair LLM reasoning with deterministic logic, with fallbacks when a model call fails.
- **Production habits.** CI pipelines, environment-based secrets, and clear READMEs.
